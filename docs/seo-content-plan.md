# Page descriptions, links, and publishing opportunities

Every published content entry already has a page-specific search description. Static pages now reuse their own descriptions for Open Graph and Twitter previews. Collection indexes also explain what readers will find. The built-HTML SEO check verifies the actual output after a production build.

Search engines may choose a different snippet for a particular query. A metadata change does not force a search result, AI citation card, thumbnail, ranking, or immediate recrawl.

## Editorial practice

- Write each introduction for a reader: what the page explains, who it helps, and what evidence or limitations it contains. Keep the metadata faithful to that text.
- Link a project to a relevant investigation or adjacent tool when the relationship helps a reader. Use descriptive anchor text. Link technical assertions to the original documentation or research.
- Add architecture diagrams, reproducible validation commands, and screenshots only from the actual project. Distinguish demonstration data, measured results, and future plans.
- Verify challenge attribution and advisory identifiers against primary sources before presenting them as independently reproduced research.

## Concrete backlink opportunities

These are proposed external edits or publications, not completed backlinks:

1. Link each owned project's repository README or project website to its specific portfolio case study. Start with Greyfield and TraceIR, where the case studies explain evidence and privacy boundaries beyond the demo.
2. Publish a reproducible TraceIR investigation guide with a synthetic input bundle, verification commands, and links to the case study and original toolkit.
3. Document the YouTube Window Theater extension's behavior and upstream attribution in its maintained project documentation. Link a relevant portfolio explanation where it adds context.
4. Share a substantive technical article with a relevant community or publication when its provenance and reproduction steps are verified. Link the specific supporting resource naturally.

Backlinks require a link on another site. Additional links within this portfolio cannot create external endorsements. External posting, outreach, and changes to other repositories were not performed as part of this refinement.
